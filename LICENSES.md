# Lizenzmatrix

Die Lizenz gilt jeweils nur für den ausdrücklich bezeichneten Bestandteil.

| Bestandteil | Lizenz |
| --- | --- |
| Eigene Skripte und Werkzeuge dieses Repositories | AGPL-3.0-only |
| Aus Wikipedia abgeleitete Fragen, Erklärungen und sonstige redaktionelle Bearbeitungen | CC BY-SA 4.0 |
| Eigene, nicht abgeleitete Inhalte | vor Veröffentlichung ausdrücklich je Inhalt ausweisen |
| Bilder, Grafiken, Audio, Video und sonstige Medien | jeweilige tatsächliche Lizenz des einzelnen Assets |

## Wikipedia-Text

Wikimedia-Texte werden grundsätzlich unter CC BY-SA 4.0 und zusätzlich unter den in den Wikimedia-Nutzungsbedingungen beschriebenen Bedingungen bereitgestellt. Dieses Repository verwendet für Wikipedia-abgeleitete Katalogtexte ausschließlich den CC-BY-SA-4.0-Pfad.

Jede veröffentlichte Frage benötigt:

- einen permanenten Link auf die konkrete deutschsprachige Wikipedia-Revision,
- die Revisions-ID,
- eine Attribution,
- einen Hinweis auf CC BY-SA 4.0 einschließlich Lizenzlink,
- bei Bearbeitungen einen Änderungsvermerk.

## Medien

Die Lizenz eines Wikipedia-Artikels wird nicht auf eingebundene Medien übertragen. Für jedes Medium werden Quelle, konkrete Quellenrevision, Urheber oder Rechteinhaber, Attribution, Lizenzbezeichnung und Lizenzlink separat dokumentiert.

Nicht eindeutig lizenzierbare oder nur im Rahmen von Fair Use verwendete Medien werden nicht übernommen.

## Lizenztrennung

Die AGPL-3.0-only für eigene Werkzeuge erstreckt sich nicht auf Kataloginhalte oder Drittmedien. Umgekehrt erstreckt sich CC BY-SA 4.0 für Wikipedia-abgeleitete Katalogtexte nicht auf die Software dieses Repositories und nicht automatisch auf Medien.

Siehe auch `docs/WIKIMEDIA-LICENSING.md`.
